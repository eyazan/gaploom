GAPLOOM — Privacy Policy

Last updated: 2026-11-25

English

  • GAPLOOM does not collect, store or share any personal data.
  • There are no accounts, no advertising, no analytics and no tracking.
  • Your progress (completed levels, stars, settings, daily streak) is saved only on your own device. Deleting the app or the website data removes it.
  • The game works offline. The web version is hosted on GitHub Pages; GitHub may keep standard server logs (see GitHub's privacy statement).
  • Sharing a daily result only happens when you tap "Share", and only the text you see is shared, through your device's own share sheet or clipboard.
  • Questions: open an issue at github.com/eyazan/gaploom.

Türkçe

  • GAPLOOM hiçbir kişisel veri toplamaz, saklamaz veya paylaşmaz.
  • Hesap, reklam, analiz veya takip yoktur.
  • İlerlemen (bitirdiğin seviyeler, yıldızlar, ayarlar, günlük seri) yalnızca kendi cihazında saklanır. Uygulamayı ya da site verilerini silmek bunları da siler.
  • Oyun çevrimdışı çalışır. Web sürümü GitHub Pages'te barındırılır; GitHub standart sunucu kayıtları tutabilir.
  • Günlük sonucu paylaşmak yalnızca "Paylaş"a dokunduğunda ve yalnızca ekranda gördüğün metinle olur.
